\chapter{Advanced GitHub}\label{chap: Advanced GitHub}

GitHub offers you free web hosting for organisations/individuals and for individual projects though something called ``GitHub Pages''.

There is a test version of the T-Exchange's (old) website---\url{https://moraymakerspace.com}---based on WordPress which currently takes up at least half a Gigabyte. The test website is currently 115 Mb in size and has extra posts! You can play with it at \url{https://the-t-exchange.github.io}.

\begin{tips}{Note}
    The test website is not 100\% identical. It is missing the contact form for now, Twitter/X images have been converted so that they display as images---you can't click through to Twitter at the moment. The usual ``T-Exchange'' header image needs to be inserted into the code that builds the web pages. (I'm working on that).

    However, it is smaller, faster and free! It is also possible to redirect our URL, \url{https://moraymakerspace.com} to point at the GitHub one \url{https://the-t-exchange.github.io}.
\end{tips}


GitHub also offers free Wikis for projects and organisations/individuals, there are also ``gists'' which are small notes, code snippets and such like.

These are most likely going to be the subject of a further talk, if enough interest can be raised.
