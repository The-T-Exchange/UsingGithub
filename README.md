# UsingGithub
Norman's presentation on the use and abuse of GitHub.

The files in this directory are the LaTeX source files, `*.tex` for Norman's presentation notes. These contain far more details than the presentation slides could. You can download a PDF of the notes, and presentation slides, on the "releases" page.

The presentation, scheduled for December 2026, is intended to introduce group members to GitHub (and a couple of alternatives) starting simple and working your way up to advanced topics on the use and abuse of https://github.com.

Enjoy.

Norman Dunbar, October 2026.
