\chapter{SSH Credentials}\label{chap: Ssh Credentials}

The preferred method of accessing GitHub remotely, is to use SSH. On Mac and Linux systems, it's already installed but the \emph{mega-secure} Windows operating system needs to have an SSH installed. OpenSSH is recommended.

\section{Generate a New SSH Key}

Windows users will have a screen to fill in, and I can't tell you what is asked for as I don't have Windows these days. You need to generate a new ``ED25519'' key linked to your email address.

On Mac and Linux:

\begin{lstlisting}
ssh-keygen -t ed25519 -C ``your_email@whatever.com''
\end{lstlisting}

You will be asked to save the key pair in a file. The default is \path{/home/norman/.ssh/id_25519} on my system. For the sake of this example, I will use \path{/home/norman/.ssh/github_norman_id_25519}  as I keep track of what the key is used for in the filename.

When prompted for a passphrase, just press return. And again when prompted to confirm the pass phrase.

\begin{tips}{Warning! Warning! Warning!}
    The key pair generated consists of a private key and a public key. The names are a clue and the only one of the two that should ever be given out, uploaded or whatever, is the \emph{public} one. The file that ends with \path{.pub} is the public one of the two.
    \textbf{Never, ever, ever allow the private key to be seen, extracted, uploaded or given away in any way, shape or form.}
\end{tips}

\section{Add the New Key to the SSH Agent}

We need to start up the ssh-agent, if it's not already running, and add our keyfile to it. \emph{Do not} use the filename with \path{.pub} on the end.
\begin{lstlisting}
eval ``$(ssh-agent -s)''
ssh-add ~/.ssh/github_norman_id_25519
\end{lstlisting}

That's our local PC configured. Next, we need to update our Github account.

\section{Updating GitHub}

We first must copy the content of the \emph{public} key of the key pair. This happens on our PC of course.

\begin{lstlisting}
cat ~/.ssh/github_norman_id_25519.pub
\end{lstlisting}

Highlight and copy the entire text that is displayed on screen. It will resemble the following---which is not any of my own keys in case you were wondering!

\begin{lstlisting}
ssh-ed25519 YADAyadaYaDa....uggawugga norman@example.com
\end{lstlisting}

\begin{itemize}
    \item Login to your account on GitHub.
    \item Click your profile picture on the far right.
    \item Click ``Settings''.
    \item On the left sidebar, click ``SSH and GPG Keys''.
    \item Back to the right, click ``New SSH key''.
    \item Add a title, be meaningful.
    \item Paste the text of your public key into the ``Key'' text-box.
    \item Click ``Add SSH key''
\end{itemize}

Now, and in the future, when you click on the green ``Download code'' button to get a repository's URL, click first on ``ssh'' and then copy the URL. The SSH URL's resemble:

\begin{lstlisting}
git@github.com:username/repository.git
\end{lstlisting}

You will be able to push code changes back to github without specifying a username and/or password---your public and private keys will do all the necessary negotiations.
