\chapter{Alternatives to GitHub}
Some people and organisations are getting a bit huffy with GitHub since Microsoft took it over some time back, and especially since Microsoft and their so-called ``AI'' cannot be trusted not to steal your code and documentation and to claim it as their own.

\section{GitLab}

Gitlab is probably the oldest alternative to GitHub. It offers public and private repositories for your projects and is not (yet?) owned by Microsoft.

It is very similar to GitHub in what it offers. There is, as you might imagine a free and a pay-for-it option, the latter offering more support and is aimed at larger organisations.

Git lab is found at \url{https://gitlab.com}.

\section{CodeBerg}

CodeBerg is probably the newest kid on the block. It only caters to free and open source projects, is a non-profit and offers similar tools and features as GitHub.

CodeBerg  is found at \url{https://codeberg.org}.
